Before You Start❗

Please read these guidelines before building the case file.

The case file system is divided into two parts: the case overview (Template 1) and the investigation report (Template 2). All Fire Marshals are expected to follow this structure to ensure consistency across all investigations.

The lead investigator is responsible for creating the main case file using Template 1. This serves as the primary post and must contain all base information about the incident, including date/time, location, assigned personnel, and the link to the associated forum topic.

The investigation report (Template 2) is to be posted as a secondary post within the same forum topic. This post contains the detailed narrative, evidence, persons of interest, and conclusion of the investigation.

Other Fire Marshals shall not edit the main case file post. Instead, they are to submit their findings, evidence, and observations in separate replies within the same topic. These contributions should follow the structure of Template 2 where applicable.

The lead investigator is responsible for reviewing all replies and ensuring that relevant findings are acknowledged and reflected in the investigation. If significant updates occur, an additional Template 2 post may be created to document new developments.

A case file must be created and completed within 48 hours of the incident. This ensures that all information remains accurate, complete, and that no relevant details are forgotten during the investigation process.
